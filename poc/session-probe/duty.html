FURSOY Cookie Protector · Experiment 4

Cookie exposure duty-cycle probe

This harness uses only the synthetic FCP-session-probe cookie and the local dummy session server. It measures one observed browser-open window; it does not claim production-site compatibility or a whole-day duty cycle.

Simulation

The harness opens the local site, logs in once, keeps it active, closes the last relevant tab, then reopens it to exercise automatic restore. After reopening, do not use the mouse or keyboard until the run ends so the real chrome.idle trigger can fire.
