FURSOY Vault source and build information
=========================================

Canonical source: https://github.com/FURSOY/fursoy-vault

The complete corresponding source for a release is the repository tree at the matching `vX.Y.Z`
tag. Release assets must be published together with that tag; do not publish an asset built from an
untagged or dirty tree.

Reproducible extension build (Node.js 22):
  cd extension
  npm ci
  npm run package

Windows companion build:
  cd native-host
  cargo build --release --locked
  dotnet tool install --global vpk --version 1.2.0
  powershell -File install/package-release.ps1

The compiler is not "whatever stable is current": native-host/rust-toolchain.toml names the exact
Rust version, and rustup installs it automatically for any cargo command run in that directory.
Together with the committed Cargo.lock and the pinned Velopack version, that is what makes a build
of a given tag reproducible rather than dependent on the day it was built. Read that file to see
which compiler produced a given release.

CI repeats the extension packaging and compares SHA-256 hashes, runs all Rust/TypeScript checks,
and publishes the resulting hashes/artifacts for comparison.
